# Phase 3 — Extra tools

Reserved for the additional native build environment and eventual transition to a separately assembled Distro Build chroot.

`capabilities.json` and `build-chroot-candidate.json` are **exploratory, not dependency-closed**. They are original hypotheses about an eventual Build chroot, not accepted extra-tools recipes or an imported LFS package list. The managed Build chroot must be assembled independently from Distro-produced artifacts.
